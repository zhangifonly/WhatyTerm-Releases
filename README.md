# WhatyTerm（网梯终端）

AI 编程会话的终端管理工具：同时管理 Claude Code、Codex、Cursor、Kiro 等 8 种 AI 编程 CLI 的会话，AI 监控自动推进，长程编程无人值守、花到额度就停，手机远程查看，同账号的几台电脑之间互看、迁移会话。

**本仓库只发布安装包，不包含源代码。**

- 下载：右侧 **Releases** 里选最新版本
- 官网、订阅：<https://term.whaty.org>　产品介绍：<https://term.whaty.org/download>
- 问题反馈：本仓库 **Issues**
- 已安装的 WhatyTerm 会自动从 term.whaty.org 检查并下载更新，不必回到这里手动下载

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片：M1/M2/M3/M4…） | `WhatyTerm-版本号-arm64.dmg` |
| macOS（Intel 芯片） | `WhatyTerm-版本号.dmg` |
| Windows 10 / 11（不需要 WSL） | `WhatyTerm-Setup-版本号.exe` |
| Linux（x64，需已装 tmux） | `WhatyTerm-版本号.AppImage`（下载后 `chmod +x` 再运行） |

`.zip`、`.blockmap`、`latest*.yml` 是自动更新用的文件，手动安装不需要。
